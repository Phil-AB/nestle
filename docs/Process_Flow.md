This process outlines how to validate a Customs Declaration (also known as a Bill of Entry or BOE) within the Ghana Revenue Authority (GRA) ICUMS system.
The workflow moves from receiving documents to validating the financial and tax details on the final declaration.
Phase 1: Pre-Clearance & Document Receipt
Before any declaration is made, the necessary paperwork must be gathered from suppliers.
Trigger: The process begins with "Pre-alerts" or the receipt of scanned clearing documents from suppliers.
Required Documents: Depending on the order type, the following are critical for the clearing agent:
Transport Document: Bill of Lading (Sea), Air Waybill (Air), or Delivery Note (Road).
Financial Document: Final Commercial Invoice.
Cargo Details: Packing List (PL).

Origin: Certificate of Origin (COO).
Phase 2: Drafting the Declaration (BOE)
Once documents are received, the data is entered into the customs system.
Generation: A Customs Declaration (BOE) is generated in the ICUMS system.
Input: The agent inputs details into specific fields based on the documents collected in Phase 1 (BL/AWB, Invoice, PL, & COO).
Phase 3: Validation & Checks (The "IMPEX" Review)
This is the core of the workflow. The draft BOE is sent to the "IMPEX" team to check for accuracy against the source documents. The following specific checks are performed:
1. Logistics & Parties Check
Shipper & Consignee: Verify these names against the Bill of Lading or Air Waybill.
Mode of Transport (Section 21): Check the Entry/Exit office code. If it reads KIA, it is an Air shipment (look for AWB). If it reads TMA, it is a Sea shipment (look for BL).
Weights: Verify the gross and net weights against the Packing List.
2. Classification Check (HS Code)
Verify Code: Check the HS Code (Commodity Code) using the Certificate of Origin.
Description Check: Read the description of goods in Section 25 to determine if the HS code is logical.
Reference: You can cross-reference the HS code using the "CET File" (Common External Tariff) to ensure the description matches the ID.
3. Valuation & Financial Check
Currency: Check Section 16 for the exchange rate used.
Incoterms (Terms of Delivery): The Customs Value is calculated based on the Incoterm (e.g., CIF, FOB). You must verify the invoice amounts based on these terms:
CFR: Invoice should state a Freight value.
CIF: Invoice should state Insurance and Freight values.
FCA/FOB: No freight value should be quoted on the invoice.
Calculation Formula: For CIF shipments, the Total Invoice Value = FOB + Insurance + Freight.
Phase 4: Duty & Tax Calculation
The final step is verifying the "Amount Payable" in the tax section (Section 40 on the form). The workflow provides specific rules for different Customs Procedure Codes (CPC):
General Calculation: Amount Payable = Tax Rate × Customs Value.
CPC 40E68: Import VAT must be paid in full.


CPC 40V02: VAT is exempted (deferred payment), resulting in 0.00 payable for that line item.


CPC 40U01 & 40W01: Import Duty is exempted. Note that for 40W01, while duty is exempted, other taxes are still paid
